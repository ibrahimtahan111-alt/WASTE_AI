# WasteAI ♻️

**Smart Waste Detection & Recycling Assistant**

WasteAI is an AI-powered platform that helps individuals and communities identify waste items, classify them (Recyclable, Hazardous, Organic, Non-Recyclable), and get eco-friendly disposal or recycling suggestions.  

## ✨ Features
- 🔍 **AI Detection** – Real-time waste detection using YOLOv8.  
- 💬 **WhatsApp Integration** – Send a photo and instantly receive recycling advice.  
- 📊 **Impact Tracking** – Track your saved CO₂, water, energy, and trees.  
- 🌍 **Facility Finder** – Locate the nearest recycling or disposal center.  
- 🏆 **Gamification** – Earn eco-badges and climb the leaderboard.  
- 🌐 **Multi-language** – English, Arabic, and French supported.  
- ⏰ **Daily/Weekly Digest** – Automated eco-reports via WhatsApp.  

## 🚀 Tech Stack
- **Backend:** Python (Flask, SQLAlchemy)  
- **AI Model:** YOLOv8 (Ultralytics)  
- **Messaging:** Twilio WhatsApp Business API  
- **Database:** SQLite / PostgreSQL  
- **Frontend:** HTML, Bootstrap, ECharts  

## 📌 About
WasteAI was developed as a final-year university project in Lebanon (2025), aiming to bring **accessible recycling technology** to the MENA region.  

> **Mission:** Empower users to recycle smarter, reduce waste, and protect the environment. 🌍
